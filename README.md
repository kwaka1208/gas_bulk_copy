# Google Driveフォルダまるごとコピー

## 概要

Google Driveでは、フォルダをまるごとコピーする機能がありません。このツールはGoogle Apps Scriptを使い、指定したフォルダの階層構造とファイルをすべて別のフォルダへコピーします。

Googleスプレッドシートのメニューから操作できます。

詳細はこちらの記事をご覧ください。  
[Google Driveでフォルダ階層をまるごとコピーする](https://zenn.dev/kwaka1208/articles/google_drive_bulk_copy)

---

## セットアップ（初回のみ）

### 1. スプレッドシートを用意する

Googleスプレッドシートを新規作成し、以下の2枚のシートを作成します。

| シート名 | 用途 |
|---|---|
| `パネル` | コピー元・コピー先のURLや通知先メールを入力する |
| `フォルダリスト` | コピーの進捗が自動で記録される |

### 2. スクリプトをデプロイする

ローカル環境でclaspを使ってスクリプトをスプレッドシートにアップロードします。

```bash
make login   # Googleアカウントで認証（初回のみ）
make push    # スクリプトをGASにアップロード
```

アップロード後、スプレッドシートを開き直すとメニューに「追加機能」が表示されます。

## 使い方

### 1. パネルシートを設定する

スプレッドシートの **パネルシート** に以下を入力します。

| セル | 内容 | 必須 |
|---|---|---|
| B1 | コピー元フォルダのURL | 必須 |
| B2 | コピー先フォルダのURL（空のフォルダを用意してください） | 必須 |
| B3 | 完了通知を受け取るメールアドレス | 任意 |

フォルダのURLはGoogle Driveでフォルダをクリックしたときにブラウザに表示されるURLをそのまま貼り付けてください。

### 2. コピーを実行する

スプレッドシートのメニューから操作します。

```
追加機能
├ 新規実行    ← 最初はこちら
└ 継続実行    ← 中断後の再開に使う
```

#### 新規実行

確認ダイアログが表示されます。「はい」を選ぶと **コピー先フォルダの内容を削除** してから新たにコピーを開始します。

> **注意：** 「はい」を選ぶとコピー先フォルダの中身が削除されます。誤って実行しないようご注意ください。

#### 継続実行

前回の続きからコピーを再開します。タイムアウトによる自動再開でも同じ処理が使われます。コピーが完了済みか未開始の場合はメッセージが表示されます。

### 3. 実行中はシートを閉じても大丈夫

GASはGoogleのサーバー上で動作するため、**メニューをクリックしたあとはスプレッドシートを閉じても構いません**。コピーはバックグラウンドで継続します。完了はB3に設定したメールアドレスに通知されます（未設定の場合は通知なし）。

### 4. タイムアウトした場合

Google Apps Scriptは1回の実行時間に制限があります（無料アカウント: 6分 / Google Workspace: 30分）。制限に近づくと自動的に停止し、**1分後に「継続実行」が自動で起動**します。ユーザー操作は不要です。

何らかの理由で自動再開されなかった場合は、手動で **追加機能 → 継続実行** をクリックしてください。

## ツールの3フェーズ

| フェーズ | 内容 |
|---|---|
| スキャン | コピー元のフォルダ構造を読み取ってシートに記録する |
| フォルダ作成 | コピー先に同じフォルダ構造を作成する |
| ファイルコピー | 各フォルダのファイルをコピーする |

---

## 進捗の確認

**フォルダリストシート** にコピーの進捗が記録されます。

| 列 | 内容 |
|---|---|
| コピー元スキャン | 「済」: スキャン完了 / 「スキップ」: アクセス不可でスキップ |
| コピー元フォルダ名 | フォルダ名 |
| コピー元フォルダURL | コピー元フォルダのURL |
| ファイル数 | そのフォルダ内のファイル数 |
| コピー済みファイル数 | コピーが終わったファイル数 |
| コピー先フォルダURL | 対応するコピー先フォルダのURL |
| 親行番号 | フォルダ階層を管理する内部情報 |

エラーが発生した場合は **エラーログシート** に日時・フェーズ・行番号・エラー内容が記録されます。

## 開発者向けコマンド

```bash
make push    # ローカルの変更をGASに反映
make pull    # GASの最新をローカルに取得
make open    # スクリプトエディタをブラウザで開く
```
